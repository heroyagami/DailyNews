# DailyNews

曹义德律师微信公众号热点深度文章库。

本仓库用于每日自动沉淀可用于微信公众号发布的热点深度文章。内容定位不是法律资讯汇总，也不是新法新规速报，而是围绕当天或最近 24—72 小时具有较高社会关注度、冲突性、讨论度和传播潜力的热点事件，形成接近可直接发布的公众号文章。

## 内容定位

核心写作方向为：

- 只做热点事件，不用常青普法、普通判例或例行行业资讯凑数；
- 对标燕梳楼式热点叙事，强调人物、冲突、利益、关系、细节与现实规则；
- 律师身份主要作为分析工具，而不是把文章写成法条讲解；
- 在事实核验的基础上，继续分析证据、程序、人性、商业逻辑和制度背景；
- 标题强调传播力，但避免过度标题党；
- 每篇文章原则上达到可以单独整理后发布到微信公众号的完整度。

## 每日产出

每日自动筛选约 5—10 个真正值得写的热点，宁缺毋滥。

重点关注：

- 社会热点与公共事件；
- 高讨论度司法案件与争议事件；
- 婚姻家庭、劳动就业、消费、房产、教育、医疗等民生热点；
- 网红、主播、企业家、平台、机构引发的公共争议；
- 具有广泛社会传播度的商业冲突、企业治理和资本市场事件；
- 少量与中国公众高度相关的重大国际热点。

普通政策发布、新法新规、常青法律知识等内容，只有在本身已经形成社会热点时才进入选题池。

## 写作原则

文章通常从热点冲突切入，而不是从法律条文切入。重点回答：

1. 这件事真正发生了什么；
2. 大家表面上在争论什么；
3. 真正被忽略的关键变量是什么；
4. 法律、证据、程序、利益和现实规则如何共同影响结果；
5. 曹义德律师对此有什么清晰、克制且有信息增量的判断。

具体法律判断以当时现行有效法律、司法解释和规范性文件为依据，并严格区分已核实事实、当事人说法、媒体报道、司法机关认定与网络传言。

## 目录结构

每日文章统一归档在：

```text
content/
└── hotspot-daily/
    └── YYYY/
        └── MM/
            └── YYYY-MM-DD.md
```

例如：

```text
content/hotspot-daily/2026/09/2026-09-11.md
```

每个 Markdown 文件是一份当天的“热点深度文章池”，其中包含若干篇可继续筛选、编辑并用于公众号发布的完整文章。

## 自动归档

本仓库由每日自动任务持续更新：

- 自动检索最近 24—72 小时热点；
- 对候选事件进行事实核验与选题筛选；
- 生成公众号深度文章；
- 保存为 Markdown；
- 自动提交到本仓库；
- 提交后再次回读文件，确认文章实际写入成功。

整个流程在云端完成，不依赖本地电脑持续开机。

## 与其他内容库的区别

`DailyNews` 专门用于 **热点深度微信公众号文章**。

它不同于普通公众号日报：普通日报强调当天信息覆盖和快速阅读；本仓库强调从热点中挑选值得深挖的事件，并输出更接近独立公众号文章的完整内容。
